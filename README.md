# Newton Fractal
Project 1 for CEN4930 - P3DG

## Overview

This application is an implementation of a Newton Fractal with Nova-style behavior. It colors the complex plane by which root of p(z) = z⁵ − 1 Newton’s method converges to from each starting point. The iteration is the relaxed form z ← z − A·p(z)/p′(z), where A is a complex number. At A = 1 this is the classic Newton fractal, but different values of A twist the basins into spirals and nested flower shapes

## Features

To move around the image, use the arrow keys.
To reset the image, press the space bar
To swirl the colors around, move your mouse within the image window.
To zoom, use the scroll wheel
